# To-Do List Application – Java Swing

## 📌 Project Overview
The **To-Do List Application** is a simple desktop-based task management application developed using Java Swing. It provides an easy way for users to add, view, and delete their daily tasks through a graphical user interface (GUI).

The application is designed for beginners to understand Java GUI programming, event handling, and basic collection management.

## ✨ Features
- **Add Task:** Add new tasks using the input field.
- **View Tasks:** Display all added tasks in a list.
- **Delete Selected Task:** Remove a selected task from the list.
- **Clear All:** Delete all tasks with confirmation.
- **Task Counter:** Display the total number of tasks.
- **Input Validation:** Prevent adding empty tasks.

## 🛠️ Technologies Used
- **Programming Language:** Java
- **GUI Framework:** Java Swing
- **Layout Manager:** BorderLayout
- **Data Structure:** DefaultListModel and JList
- **Event Handling:** ActionListener
- **IDE:** NetBeans / Eclipse / IntelliJ IDEA

## ▶️ How to Run the Project

**Step 1:** Install Java JDK (Java 8 or later).

**Step 2:** Clone the repository.

```bash
git clone https://github.com/your-username/To-Do-List-Application.git
```

**Step 3:** Open the project folder.

**Step 4:** Compile the Java file.

```bash
javac TodoListApp.java
```

**Step 5:** Run the application.

```bash
java TodoListApp
```

## 🖥️ How to Use
1. Launch the application.
2. Enter a task in the text field.
3. Click the **Add Task** button.
4. View the added tasks in the task list.
5. Select a task and click **Delete Selected** to remove it.
6. Click **Clear All** to remove all tasks after confirmation.
7. The task counter automatically updates after each operation.

## ⚙️ Limitations
- Tasks are stored temporarily in memory.
- Tasks are not saved permanently.
- All tasks are removed when the application is closed.
